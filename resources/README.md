This directory holds upstream inputs and generated assets.

## Provenance

- knuth/tex/ and knuth/tangle/ are downloaded from https://ctan.org/tex-archive/systems/knuth/dist (at 2026-08-23)
- knuth/plain/base/ is downloaded and extracted from https://mirrors.ctan.org/macros/plain/base.zip (at 2026-09-20)
- knuth/plain/fonts/cm/ is downloaded and extracted from https://mirrors.ctan.org/fonts/cm/tfm.zip (at 2026-09-20)
- knuth/plain/fonts/manfnt/manfnt.tfm is downloaded from https://tug.ctan.org/systems/apltex/amsfonts/tfm/manfnt.tfm (at 2026-09-21)
- jitex/trip.ch is created by knuth/tex/tripman.tex
- jitex/tangle.pas is produced by tangle from knuth/tangle/tangle.web
- jitex/plain-visual.tex is written by this project
- fonts/jitex-*.woff2 are generated by fonts/tools/ from the AMS/Bluesky Type 1 fonts at https://mirrors.ctan.org/fonts/amsfonts/ (at 2026-09-25); see fonts/tools/README.md. The .otf intermediates are not checked in.
