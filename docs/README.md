# docs/

> 稳定设计文档目录。只放跨模块的、长期有效的设计文档。

## 原则

- **不放临时文档**：任务追踪去 `../task.md`，问题去 `../issue.md`。
- **代码即文档**：实现细节去代码注释，不放这里。
- **稳定优先**：这里的文档应该很少修改。

| productions.md | Pascal 语法产生式参考 |
